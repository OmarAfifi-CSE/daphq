questions.

Need help with something else? ↗
Do I need to turn on a hotspot or type IP addresses?+

Usually no. When both devices are nearby with Wi-Fi and Bluetooth on, Daphq finds them automatically and negotiates a direct 5GHz link. Manual IP entry is always there if you ever need it on a locked-down network.

Why did Android ask to confirm Wi-Fi on my very first transfer?+

Android shows a one-time system confirmation the very first time an app requests a direct local Wi-Fi link. Daphq keeps your link credentials consistent so future transfers reconnect smoothly without manual re-selection.

What if I already turned on Windows Mobile Hotspot manually?+

Daphq respects it. If your Windows Mobile Hotspot is already running, Daphq won't change its name or password and won't shut it down after the transfer completes.

Does transferring files use my internet plan or mobile data?+

No. Every byte moves locally between your devices inside the room—never over mobile data and never through any cloud server.

Can I send huge 4K videos or whole folders safely?+

Yes. There are no file-size or item-count limits. Subfolders keep their structure, and if a file with the same name already exists, Daphq renames the new copy cleanly (like photo (1).jpg) instead of overwriting.

Can anyone nearby drop files onto my device without asking?+

Never. When someone wants to send files, your receiving screen shows who is sending, how many items, and the total size—and waits for you to tap Accept.
